# Security Policy

The security of our users and customers is extremely important to us.

---

## Reporting a Vulnerability

Please **do not create public GitHub issues** for security vulnerabilities.

Instead, report them privately via:

📧 hello@setoo.co

Include:

- Description
- Steps to reproduce
- Potential impact
- Screenshots (if applicable)

---

## Response Timeline

| Stage | Timeline |
|---------|----------|
| Initial acknowledgement | Within 2 business days |
| Investigation | 5–10 business days |
| Resolution | Depends on severity |

---

## Supported Versions

We actively support the latest stable releases.

Older versions may not receive security patches.

---

## Responsible Disclosure

We appreciate responsible disclosure and ask researchers to:

- Avoid disrupting production systems
- Do not access customer data
- Give us reasonable time before public disclosure

Thank you for helping keep Setoo secure.
