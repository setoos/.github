# Contributing to Setoo

Thank you for your interest in contributing to Setoo.

We welcome contributions that improve our projects, documentation, developer experience, and open-source ecosystem.

---

## Ways to Contribute

- Report bugs
- Suggest new features
- Improve documentation
- Fix issues
- Improve performance
- Add tests
- Improve accessibility
- Refactor existing code

---

## Before You Start

Please search existing Issues before opening a new one.

For larger features, open a Discussion first so we can align on the implementation.

---

## Development Process

1. Fork the repository
2. Create a feature branch

```bash
git checkout -b feature/my-feature
```

3. Make your changes

4. Commit using meaningful commit messages

```bash
feat(auth): add Google OAuth support
```

5. Push your branch

```bash
git push origin feature/my-feature
```

6. Open a Pull Request

---

## Coding Standards

We value:

- Clean Architecture
- Readable Code
- Small Pull Requests
- Proper Documentation
- Type Safety
- Automated Testing

---

## Pull Request Checklist

- Code builds successfully
- Tests pass
- Documentation updated
- No breaking changes unless documented
- Follows project style guide

---

## Code Style

Please follow:

- ESLint
- Prettier
- TypeScript strict mode
- Conventional Commits
